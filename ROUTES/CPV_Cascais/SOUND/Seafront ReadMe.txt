Please be aware that MSTS wav format quality(11025 khz)
is only a quarter of that of CD quality (44100khz)

NOTE: if you place the Sound source object  
( SEAFRONT ) close to another one ( SEAFRONT)
you will increase the  the sound volume. 

IF YOU GET AN UNNATURAL METALIC TWANG TO YOUR
SOUND: Delete the sms and wav files from the sounds 
folder from the route that you are using and copy and paste
the sms file first into the souns folder of the route. If the 
problem persists when you have placed the sound object
in Route Editor, delete the sound object and place it again.


INSTRUCTIONS FOR INSTALLATION:

IMPORTANT: COPY AND PASTE THE SMS FILE 
BEFORE THE WAV FILE

1. Open Program files\micosoft games\Train Simulator
    \Routes.
2.  Choose the route of your choice.
3.  Open the route's Sound folder and copy and paste
     the SEAFRONT.sms  and the SEAFRONT.wav 
     file into it.
4.  Open  the ssource.dat with wordpad and put the 
     following line into it:  

Sound  ( Name  ( "SEAFRONT" )    FileName   ( "SEAFRONT.sms" )      )

5.  Click Edit and click Save.

6.  Open ROUTE EDITOR
7.  select and open the route which you placed the files 
      into
8.   Click "more" in the placement window and select
      Ssource.
9.   Scroll down to SEAFRONT and click .

10. Click the last icon in the top column (top right-hand
      corner) from the MODE window.
11. Double click on area that you wish to use and a slender tall 
      green box will appear with the sound emanating from
      it.
