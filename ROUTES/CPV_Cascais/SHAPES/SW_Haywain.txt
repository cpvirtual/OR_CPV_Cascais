How to install:

Unzip the contents of this archive into a temporary folder. Move the *.S and *.SD files into the 'Shapes' subfolder of your Route folder. Move the *.ACE file into the Textures subfolder of your Route folder, move the contents of the 'Snow' folder into the 'Snow' folder of the Textures folder and move the contents of the 'Night' folder into the 'Night' folder of the Textures folder. Place the following lines in the *.REF file of your Route:

Static (
    Class           ( Buildings )
    Filename        ( SW_Haywain.s )
    Align           ( None )
    Description     ( SW_Haywain )
        )

The model can now be placed in your route using the Route Editor.
-------------------------------------------------------------------------------------------

The Model:

The model was built and textured in 2003 by Jur Snijder using Abacus Train Sim Modeler, based on Willie Lott's cottage featuring in the painting 'The Haywain' by Constable and photographs of the cottage as it looks today. It will look best on the banks of a shallow stream in Suffolk... 

The model contains approx. 220 polygons, reduced to 77 beyond 400 m.
