Installation notes for the: "Mobile Container Loader and Yard Tractor"

TO INSTALL:

Unzip the shape files ending in '.s' and '.sd' into the shapes directory of the route you wish to use the models. 
Unzip the texture files ending in '.ace' to the textures directory. 
Add the following to the end of your .ref file for the route:

Static (
	FileName ( rchpckrA.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "ReachPackerA" )
)
Static (
	FileName ( rchpckrB.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "ReachPackerB" )
)
Static (
	FileName ( rchpckrC.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "ReachPackerC" )
)
Static (
	FileName ( yardtractor.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "yardtractor" )
)
Static (
	FileName ( contchassis.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "containerchassis" )
)
Static (
	FileName ( container48.s )
	Class ( "3DCanvas" )
	Align ( None )
	Description ( "container48" )
)

Note:
Properly rotate the objects into position using the arrow keys on the number keypad.
Rotate Left: CNTL <-  

Rotate Right: CNTL ->

Rotate Down:     | 
                \|/  

Rotate Up:    /|\
               |
