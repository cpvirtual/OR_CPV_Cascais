X2000 for MSTS

This X2000 trainset, model and texture, is made by Erik Falkenström.

The trainsets is operated by SJ in Sweden, and one trainset is in
china, operated by GaungShen Railway Company Limited, GaungDong.

INSTALL:

Unzip all files to your MSTS folder, start game and have fun!



The train is freeware, but if you would like to make a new skin,
this file must be with it, and renamed "readme_org.txt"
